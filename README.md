# Precio Justo Web

Landing page pública de Precio Justo, creada con Vue 3, Quasar y Vite.

## Requisitos

- Node.js 22.22 o superior.

## Desarrollo

```bash
npm install
npm run dev
```

También se puede iniciar directamente con:

```bash
quasar dev
```

## Verificación y build

```bash
npm run lint:check
npm run build
```
